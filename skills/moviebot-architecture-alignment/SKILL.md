# MovieBot architecture alignment

## Before inventing or changing product behavior
1. Open the Architecture Page: your instance Architecture document (public reference: `docs/architecture.md`; keep your instance copy and its link private)
2. Prefer locked owner decisions over improvisation
3. Privacy is **phase two** — do not invent a privacy policy
4. MIT license; private prototype until v1; then public main repo
5. Single-human instance; TMDB metadata cached in SQLite; host-normal write approval

If the Page and a chat request conflict, follow the latest explicit owner instruction and then update the Page (or ask your maintainer agent to).
